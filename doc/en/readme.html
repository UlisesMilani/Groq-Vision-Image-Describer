Groq Vision Image Describer

Author: Antigravity, Ulises Milani

Version: 1.0.0

Description

This is a global add-on for the NVDA screen reader. Its goal is to provide detailed image descriptions using advanced artificial intelligence (vision models).

The add-on is capable of reading the original path of selected images in Windows Explorer to send them in maximum quality. If you are using an application where there is no physical file selected (e.g., browsing the web or using WhatsApp), the add-on will intelligently take a screenshot of the area where the NVDA focus is currently located and send it for analysis.

Keyboard Shortcuts

  • NVDA + Shift + V: Analyzes and describes the currently focused image or the selected file in Windows Explorer.

API Configuration (For Developers/Advanced Users)

The add-on connects to OpenRouter servers to process the image using the free NVIDIA Vision model. For it to work correctly, you must provide your own OpenRouter API key in the source code.

  1. Open the NVDA menu (Insert + N).
  2. Go to Preferences and then Settings.
  3. Look for the IA Vision (OpenRouter) category in the list on the left.
  4. Paste your key in the text box and press OK.

Note: If you leave the box blank, the add-on will try to use a free default key, which might be slower if many users are using it at the same time.

Known Limitations

As it uses the free tier of the APIs, the service may be congested or have strict rate limits depending on OpenRouter.
