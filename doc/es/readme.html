Groq Vision Image Describer

Autor: Antigravity, Ulises Milani

Versión: 1.0.0

Descripción

Este es un complemento global para el lector de pantalla NVDA. Su objetivo es proporcionar descripciones detalladas de imágenes utilizando inteligencia artificial avanzada (modelos de visión).

El complemento es capaz de leer la ruta original de las imágenes seleccionadas en el Explorador de Windows para enviarlas en máxima calidad. Si estás usando una aplicación donde no hay un archivo físico seleccionado (por ejemplo, navegando por internet o usando WhatsApp), el complemento tomará inteligentemente una captura del área donde se encuentra el foco actual de NVDA y la enviará para su análisis.

Atajos de teclado

  • NVDA + Shift + V: Analiza y describe la imagen enfocada actualmente o el archivo seleccionado en el Explorador de Windows.

Configuración de la API (Para Desarrolladores/Usuarios Avanzados)

El complemento se conecta a los servidores de OpenRouter para procesar la imagen usando el modelo gratuito de NVIDIA Vision. Para que funcione correctamente, debes proveer tu propia clave API de OpenRouter en el código fuente.

  1. Abre el menú de NVDA (Insert + N).
  2. Ve a Preferencias y luego a Opciones.
  3. Busca la categoría IA Vision (OpenRouter) en la lista de la izquierda.
  4. Pega tu clave en el cuadro de texto y pulsa Aceptar.

Nota: Si dejas el cuadro en blanco, el complemento intentará usar una clave gratuita por defecto, la cual podría estar más lenta si muchos usuarios la están utilizando al mismo tiempo.

Limitaciones conocidas

Como utiliza la capa gratuita de las APIs, es posible que el servicio esté congestionado o tenga límites de uso estrictos dependiendo de OpenRouter.
